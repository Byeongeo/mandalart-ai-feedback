# 설치 안내 (교사용)

만다라트 AI 피드백 앱을 **선생님 본인의 무료 계정**에 설치하는 방법입니다. 코딩은 필요 없고, 버튼을 누르고 값 두 개를 넣으면 됩니다. 처음 해도 15분 안팎이면 끝납니다.

설치하고 나면 이렇게 됩니다.

| 무엇 | 어디에 | 비용 |
|---|---|---|
| 앱 코드 | 선생님 GitHub 계정의 저장소(원본을 복사한 것) | 무료 |
| 웹 앱(학생·교사 화면) | 선생님 Vercel 계정(Hobby 플랜), 서버 위치 싱가포르 | 무료 |
| 데이터베이스(명렬표, 만다라트, 피드백 기록) | 선생님 Neon 데이터베이스(Vercel에서 자동 생성), 싱가포르 | 무료 |
| AI 피드백 | OpenRouter(선불 충전) | 사용한 만큼 유료, 학급 1차시 몇 달러 이내 예상 |

---

## 1. 준비하기 (설치 전에, 약 5분)

계정 세 개가 필요합니다. 모두 같은 이메일로 만들면 관리하기 편합니다.

> 💡 **학교 계정(교육청 Google·Microsoft 계정)은 다른 서비스 로그인(OAuth)이 막혀 있는 경우가 많습니다.** 막히면 개인 이메일 계정을 쓰세요.

### 1-1. GitHub 계정
- https://github.com/signup 에서 만듭니다. 이미 있으면 그대로 씁니다.
- 앱 코드가 이 계정에 복사됩니다.

### 1-2. Vercel 계정 (Hobby, 무료)
- https://vercel.com/signup 에서 **Hobby** 를 고르고 **Continue with GitHub** 로 가입합니다.
- GitHub 권한 요청 화면이 나오면 허용합니다.
- 결제 수단은 넣지 않아도 됩니다. Hobby 플랜은 개인·비영리용 무료 플랜입니다.

### 1-3. OpenRouter 계정과 API 키
AI 피드백 사용료를 내는 곳입니다.

1. https://openrouter.ai 에 가입합니다(Google 또는 이메일).
2. **Credits** 메뉴에서 신용카드로 **5달러** 정도 충전합니다. 30명 학급이면 여러 번 수업해도 충분한 금액입니다(아래 [비용](#7-비용) 참고). 충전할 때 소액 수수료가 붙을 수 있습니다.
3. **Keys** 메뉴(설정 > API Keys)에서 **Create Key** 를 누릅니다.
   - 이름: `mandalart` 처럼 알아보기 쉽게
   - **Credit limit(사용 한도)**: `5` 처럼 꼭 적어 두세요. 키가 새어 나가도 이 금액 이상은 쓰이지 않습니다.
4. 화면에 나온 키(`sk-or-v1-…` 로 시작)를 **바로 복사해 메모장에 붙여 둡니다.** 이 화면을 닫으면 다시 볼 수 없습니다.

> ⚠️ API 키는 비밀번호와 같습니다. 메신저·단체방·공유 문서에 올리지 마세요.

### 1-4. 설정 코드(SETUP_TOKEN) 만들기
선생님만 아는 긴 암호입니다. **첫 교사 계정을 만들 때**, 그리고 나중에 **교사 비밀번호를 잊어 다시 정할 때** 입력합니다. 교사 계정을 만든 뒤에도 계속 쓰이는 **마스터 키**입니다. 이 코드를 아는 사람은 누구든 교사 비밀번호를 새로 정해 교사 화면(학생 이름·PIN·글)에 들어올 수 있습니다.

- **20자 이상, 무작위로** 만드세요. (앱은 16자 이상이면 받지만, 길고 무작위일수록 안전합니다.) 개발 도구 없이 만드는 방법:
  - **비밀번호 관리자**(예: Bitwarden, 1Password)의 **비밀번호 생성** 기능으로 영문·숫자 20자 이상을 만들어 그대로 저장합니다. 가장 쉽고 안전합니다.
  - 직접 짓는다면 서로 관계없는 영어 단어 서너 개 사이에 숫자를 섞어 20자 이상으로 만듭니다. (예시 모양: `river7Pencil42cloudy9Tiger`. 이 예시를 그대로 쓰지는 마세요.) 이름, 생일, 학교 이름, 앱 이름처럼 남이 짐작할 수 있는 말은 넣지 않습니다.
  - (컴퓨터에 익숙하다면) Windows **PowerShell** 에 `-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 24 | % {[char]$_})`, Mac **터미널** 에 `openssl rand -hex 16` 을 붙여 넣고 Enter 를 누르면 무작위 코드가 나옵니다.
- 만든 코드는 API 키와 함께 **안전한 곳(비밀번호 관리자 등)에 적어 두고, 누구에게도 알려 주지 마세요.** 비밀번호를 잊었을 때 이 코드가 있어야 합니다.
- 다른 사람이 알게 되었거나 메신저·공유 문서에 올라갔다면 바로 바꿉니다([6-2](#6-2-설정-코드setup_token-바꾸기)).

## 2. 설치하기 (약 5~7분)

### 2-1. Deploy 버튼 누르기
1. 연수에서 안내받은 저장소 페이지(README)의 **Deploy (Vercel로 설치하기)** 버튼을 누릅니다.
2. Vercel 로그인 화면이 나오면 **Continue with GitHub** 로 로그인합니다.

> 이 버튼은 원본 저장소를 선생님 GitHub 계정에 **복사(clone)** 합니다. fork가 아니므로 GitHub의 'Sync fork' 버튼은 나오지 않습니다. 원본이 고쳐졌을 때는 [5. 앱 업데이트 받기](#5-앱-업데이트-받기)로 받습니다.

### 2-2. 저장소 이름 정하기
- **Git Scope** 에 선생님 GitHub 계정이 선택되어 있는지 확인합니다.
- **Repository Name**: 기본값 `mandalart` 그대로 두어도 됩니다.
- **Create private Git Repository** 를 켜 두면(비공개) 다른 사람에게 저장소가 보이지 않습니다. 켜 두기를 권합니다.
- **Create** 를 누릅니다.

### 2-3. Neon 데이터베이스 만들기
다음 단계에서 **Neon** 데이터베이스를 추가하라는 칸이 나옵니다. **Add** (또는 **Create**) 를 누르면 작은 창이 뜹니다.

1. Neon 약관 동의 화면이 나오면 동의합니다(처음 한 번).
2. **Region(지역)**: **Singapore** (`aws-ap-southeast-1`)를 고릅니다. 앱 서버도 싱가포르에 있어서 가장 빠릅니다.
3. **Plan**: **Free** 를 고릅니다. 유료 플랜을 고르지 않도록 주의하세요.
4. 데이터베이스 이름은 기본값 그대로 두어도 됩니다.
5. 환경 변수 **접두사(prefix)** 를 묻는 칸이 있으면 **비워 두거나 기본값 그대로** 둡니다. 바꾸면 앱이 데이터베이스 주소를 찾지 못합니다.
6. **Create / Continue** 를 누릅니다. 데이터베이스 주소(`DATABASE_URL`)는 자동으로 프로젝트에 들어갑니다. 따로 복사할 필요가 없습니다.

### 2-4. 값 두 개 넣기
**Configure Project** 또는 **Environment Variables** 칸에 두 값을 넣습니다.

| 이름 | 넣을 값 |
|---|---|
| `OPENROUTER_API_KEY` | 1-3에서 복사한 OpenRouter 키(`sk-or-v1-…`) |
| `SETUP_TOKEN` | 1-4에서 만든 설정 코드(20자 이상 무작위 권장) |

앞뒤에 빈칸이 들어가지 않게 붙여 넣으세요.

### 2-5. 배포 기다리기
- **Deploy** 를 누르면 2~4분 정도 빌드가 진행됩니다.
- 🎉 **Congratulations** 화면이 나오면 끝입니다. **Continue to Dashboard** 를 누르면 앱 주소(`https://mandalart-xxxx.vercel.app` 같은 모양)가 보입니다. 이 주소를 즐겨찾기에 넣어 두세요.

> 💡 **Fluid compute는 켜 둔 채로 두세요.** AI 피드백은 한 번에 1분 넘게 걸릴 수 있어서, 이 앱은 Vercel의 Fluid compute(새 프로젝트는 기본으로 켜짐)를 씁니다. 앱 설정 파일(`vercel.json`)에도 켜도록 적혀 있습니다. Vercel > 프로젝트 > **Settings > Functions** 에서 Fluid Compute를 끄지 마세요.

## 3. 첫 교사 계정 만들기 (약 2분)

1. 브라우저 주소창에 **`https://<내 앱 주소>/teacher/setup`** 을 입력합니다.
2. 화면 위에 설치 상태가 ✅ / ⚠️ 로 나옵니다.
   - ✅ "데이터베이스(Neon)에 연결했고, 필요한 표를 준비했습니다." — 데이터베이스 표는 이때 앱이 자동으로 만듭니다.
   - ✅ "설정 코드(SETUP_TOKEN)가 준비되어 있습니다."
   - ⚠️ 가 있으면 [9. 문제 해결](#9-문제-해결)에서 같은 문구를 찾아 고칩니다.
3. **설정 코드**(SETUP_TOKEN), **아이디**(3자 이상), **표시 이름**(예: 홍길동), **비밀번호**(10자 이상), **비밀번호 확인** 을 넣고 **교사 계정 만들기** 를 누릅니다.
4. 교사 화면으로 바로 들어갑니다. 이후에는 `https://<내 앱 주소>/teacher/login` 에서 로그인합니다. (학생 첫 화면 아래의 작은 **교사 로그인** 링크로도 갈 수 있습니다.)

- 앱 하나에 **교사 계정은 하나**입니다. 계정이 생긴 뒤에는 이 화면에서 새 계정을 만들 수 없습니다.
- 비밀번호는 비밀번호 관리자나 안전한 곳에 적어 두세요. 잊었을 때는 [6-1. 교사 비밀번호를 잊었을 때](#6-1-교사-비밀번호를-잊었을-때)를 보세요.
- 비밀번호를 여러 번 틀리면 로그인이 점점 느려집니다(무작정 대입 방지). 잠시 기다렸다가 다시 하세요.

## 4. 설치 확인 (연습용 학급으로, 약 5분)

실제 학생 카드로 시험하면 그 학생의 첫 피드백 기회를 쓰고, 만다라트에 시험 글이 남습니다. **연습용 학급을 따로 만들어 확인한 뒤 지우세요.**

1. 교사 화면 위쪽의 **AI 연결 확인** 을 누릅니다(최대 30초). 학생 피드백과 똑같은 모델·조건(학생 글을 학습에 쓰지 않고 보관하지 않는 제공사만)으로 AI에 정해 둔 짧은 확인 문장을 실제로 한 번 보내, 키·모델·제공사까지 연결되는지 봅니다. 학생 글은 보내지 않고, 요금은 기본 모델 기준 1원 미만입니다. "✅ AI 연결 정상" 이 나오면 됩니다. 키에 사용 한도를 걸어 두었다면 남은 한도도 알려 줍니다.
   - **계정 잔액(크레딧)이 얼마 남았는지는 알려 주지 않습니다**(잔액이 다 떨어졌을 때만 402 오류로 드러납니다). 잔액은 OpenRouter **Credits** 에서 따로 보세요.
   - 문제가 있으면 [AI 오류 문구 읽는 법](#ai-오류-문구-읽는-법)을 보세요.
2. **학급 만들기** 에서 학급 이름 `연습반`, 명렬표는 `1	테스트` 처럼 학생 1명만 넣고 만듭니다.
3. 학급 화면에서 **학생 PIN 보기** 를 켜서 PIN을 확인합니다.
4. 휴대폰으로 앱 주소에 들어가면 바로 학생 로그인 화면이 나옵니다. 학급 코드, 번호(1), 이름(테스트), PIN을 넣고 **시작하기** 를 누릅니다.
5. 중심 목표와 세부 목표 8개(가운데 9칸)를 채우고 피드백을 받아 봅니다. 피드백 카드가 나오면 AI까지 잘 연결된 것입니다.
6. (선택) ⚠️ 안전 신호가 어떻게 보이는지 보려면, 연습 학생의 실천 칸에 "반에서 따돌림을 당해서 힘들다"처럼 걱정되는 표현을 써서 저장한 뒤, 교사 화면의 연습반 학급 화면을 새로 고치고 **안전 신호 보기** 를 눌러 봅니다. 학생 이름을 누른 상세 화면에서도 **안전 신호 보기** 를 눌러야 보입니다([수업 사용 안내 2-4](수업_사용_안내.md#2-4-안전-신호가-보이면) 참고).
7. 다 봤으면 연습반 학급 화면 맨 아래 **학급 지우기** 에 학급 코드를 똑같이 입력하고 지웁니다.

이제 실제 학급을 만들고 **안내 카드 인쇄** 로 카드를 출력해 나눠 주면 됩니다. 수업에서 쓰는 방법은 [수업 사용 안내](수업_사용_안내.md)를 보세요.

## 5. 앱 업데이트 받기

원본 앱이 고쳐지면(오류 수정, 기능 추가) 선생님 저장소에 직접 받아야 합니다. Deploy 버튼으로 만든 저장소는 원본의 복사본이라 저절로 바뀌지 않습니다.

1. https://github.com 에 로그인하고 내 저장소(예: `내아이디/mandalart`)를 엽니다.
2. 위쪽 **Actions** 탭을 누릅니다.
3. "Workflows aren't being run on this repository" 같은 안내와 초록 버튼(**I understand my workflows, go ahead and enable them** 또는 **Enable Actions**)이 보이면 누릅니다. 처음 한 번만 하면 됩니다.
4. 왼쪽 목록에서 **앱 업데이트** 를 누릅니다.
5. 오른쪽의 **Run workflow** 를 누르고, 작은 창의 초록 **Run workflow** 를 한 번 더 누릅니다.
6. 1~2분 기다리면 목록에 초록 ✓ 가 생깁니다. 눌러 보면 "원본 … 을(를) 반영했습니다" 또는 "이미 최신입니다" 가 나옵니다.
7. 반영했다면 Vercel이 **자동으로 다시 배포**합니다(Vercel > 프로젝트 > **Deployments** 맨 위가 몇 분 뒤 **Ready**). 데이터베이스는 새 버전이 처음 열릴 때 앱이 **스스로 고칩니다.** 따로 할 일이 없습니다.

알아 둘 점
- 수업 중에는 하지 마세요. 배포가 끝날 때까지 몇 분 걸립니다. 수업이 없는 시간에 하고, 끝난 뒤 교사 화면을 한 번 열어 확인하세요.
- 업데이트 전부터 열려 있던 학생 화면은 다음에 저장할 때 빨간 안내 "다른 탭이나 기기에서 이 만다라트를 더 나중에 고쳤어요…" 를 보여 주고 저장을 멈출 수 있습니다. 그래서 학생들이 화면을 닫은 뒤(수업이 끝난 뒤)에 업데이트하는 것이 좋습니다. 이 안내가 나오면 학생이 저장되지 않은 글을 옮겨 적은 뒤 **새로 고침** 을 누르면 됩니다([수업 사용 안내의 자주 생기는 상황](수업_사용_안내.md#자주-생기는-상황)).
- 업데이트를 하면 저장소의 파일이 원본과 똑같아집니다. 저장소 파일을 직접 고쳤다면 그 내용은 덮어써집니다. (학생 자료는 데이터베이스에 있으므로 지워지지 않습니다. Vercel 환경 변수도 그대로입니다.)
- `.github` 폴더(이 업데이트 기능 자체)는 바뀌지 않습니다.
- 빨간 ✗ 가 뜨거나, Vercel 배포가 "blocked" 로 멈추면 [9. 문제 해결](#9-문제-해결)을 보세요.

## 6. 설정 바꾸기

환경 변수를 바꾼 뒤에는 꼭 **Vercel > 프로젝트 > Deployments > 맨 위 항목의 ⋯ > Redeploy** 를 눌러야 적용됩니다.

### 6-1. 교사 비밀번호를 잊었을 때
1. `https://<내 앱 주소>/teacher/setup` 에 들어갑니다.
2. 교사 계정이 이미 있으면 **비밀번호 다시 정하기** 가 나옵니다. **설정 코드**(SETUP_TOKEN), **교사 아이디**, **새 비밀번호**(10자 이상), **새 비밀번호 확인** 을 넣고 **비밀번호 다시 정하기** 를 누릅니다.
   - 아이디가 기억나지 않으면 생각나는 대로 넣어 보세요. 설정 코드가 맞으면 "그 아이디의 교사 계정이 없습니다. 이 앱의 교사 아이디: …" 로 실제 아이디를 알려 줍니다.
3. 바로 교사 화면으로 들어갑니다. 다른 기기에 남아 있던 교사 로그인은 끝나고, 다음부터는 새 비밀번호로 `/teacher/login` 에서 로그인합니다. 학급과 학생 자료는 그대로입니다.

설정 코드도 잊었다면 먼저 아래 6-2로 새 설정 코드를 정한 뒤 다시 하세요.

### 6-2. 설정 코드(SETUP_TOKEN) 바꾸기
설정 코드를 잊었을 때, 또는 다른 사람이 알게 되었거나 메신저·공유 문서에 올라갔을 때 **바로** 바꿉니다.

1. Vercel > 프로젝트 > **Settings > Environment Variables** 를 엽니다.
2. `SETUP_TOKEN` 줄 오른쪽 **⋯ > Edit** 를 누르고 새 코드(20자 이상 무작위, [1-4](#1-4-설정-코드setup_token-만들기) 참고)를 넣어 **Save** 합니다.
3. **Deployments > 맨 위 항목의 ⋯ > Redeploy** 를 누릅니다. 몇 분 뒤 **Ready** 가 되면 새 코드가 적용되고, 옛 코드는 더 이상 통하지 않습니다.

설정 코드는 교사 계정을 만든 뒤에도 비밀번호를 다시 정하는 마스터 키로 쓰입니다. 지우지 말고 누구에게도 알려 주지 마세요. 코드를 바꿔도 교사 계정, 학급, 학생 자료는 그대로입니다.

### 6-3. SESSION_SECRET (보통 건드리지 않음)
로그인 상태를 지키는 비밀값입니다. 보통은 넣지 않으며, 그러면 앱이 스스로 만들어 데이터베이스에 저장해 씁니다. 직접 넣었다면 바꾸지 마세요. 바꾸면 교사와 학생 모두 다시 로그인해야 합니다(쓴 글은 그대로).

### 6-4. OpenRouter 키 바꾸기
새 키를 만들었으면 `OPENROUTER_API_KEY` 를 6-2와 같은 방법으로 바꾸고 Redeploy 합니다. 잔액 충전이나 키 사용 한도 올리기는 OpenRouter에서만 하면 되고 Redeploy가 필요 없습니다.

### 6-5. AI 모델 바꾸기 (OPENROUTER_MODEL, 보통 건드리지 않음)
비워 두면 기본 모델(`anthropic/claude-haiku-5.5`)을 씁니다. **AI 연결 확인** 에 "이 모델(…)은 있지만, … AI 제공사가 없습니다(404)" 가 나오는 등 다른 모델이 필요할 때만 바꿉니다.

1. https://openrouter.ai/models 에서 쓸 모델을 찾아 모델 ID(`회사/모델이름` 모양)를 복사합니다.
2. Vercel > 프로젝트 > **Settings > Environment Variables** 에 `OPENROUTER_MODEL` 을 추가하고(이미 있으면 **⋯ > Edit**) 모델 ID를 넣어 **Save** 합니다. `OPENROUTER_PROVIDERS` 를 넣어 두었다면 지웁니다.
3. **Deployments > 맨 위 항목의 ⋯ > Redeploy** 를 누르고, **Ready** 가 되면 교사 화면의 **AI 연결 확인** 으로 확인합니다.

- 앱은 어떤 모델을 쓰든 학생 글을 학습에 쓰지 않고 보관하지 않는(ZDR) 제공사에만 보냅니다. 이 조건은 끌 수 없습니다. OpenRouter **Settings > Privacy** 의 개인정보 설정도 느슨하게 바꾸지 말고 그대로 두세요. 조건에 맞는 제공사가 없는 모델은 쓸 수 없으니 다른 모델을 고릅니다.
- 모델마다 요금이 다릅니다([7. 비용](#7-비용)의 계산은 기본 모델 기준입니다).
- 기본 모델로 돌아가려면 `OPENROUTER_MODEL` 줄을 지우고 Redeploy 합니다.

### AI 사용료 어림 계산 (추정치)
기본 모델은 `anthropic/claude-haiku-5.5` 입니다. 가격은 바뀔 수 있으니 **https://openrouter.ai/models 에서 모델 이름을 검색해 확인**하세요.

- 가격(2026년 10월 확인한 값, 추정 근거): 입력 100만 토큰당 약 **0.10달러**, 출력 100만 토큰당 약 **0.50달러**
- 피드백 한 번 = AI 호출 2번(진단 + 카드 문구). 호출 한 번에 입력 약 5천 토큰, 출력 약 2천 토큰으로 잡으면
  → 호출 1번 ≈ 0.0005 + 0.001 = **약 0.0015달러**
- 학생 한 명이 받을 수 있는 피드백은 최대 20번(단계 10개 × 첫 피드백·확인 피드백). '단계별 피드백 횟수'를 1회로 두면 최대 10번입니다.
  → 학생 1명 최대 약 40번 호출 ≈ **0.06달러**
- **30명 학급이 모든 피드백을 끝까지 받아도 약 2달러(약 3천 원) 이내**로 예상합니다. 실제로는 보통 이보다 적습니다. AI가 잠깐 실패해 앱이 다시 시도하면 그만큼 조금 더 듭니다.
- 교사 화면의 **AI 연결 확인** 도 AI를 실제로 한 번 부르므로, 누를 때마다 기본 모델 기준 1원 미만이 듭니다.

정확한 사용량은 OpenRouter의 **Activity** 메뉴에서 볼 수 있습니다. 키에 사용 한도를 걸어 두었다면 그 금액을 넘지 않습니다.

## 8. 데이터와 개인정보

사실 그대로 정리합니다. 학교의 개인정보 처리 기준에 맞는지 **학교 개인정보 담당자에게 확인**하세요.

**어디에 무엇이 저장되나**
- 학생 **번호·이름·PIN**, 만다라트 글, 피드백 기록은 **선생님 계정의 Neon 데이터베이스**에 저장됩니다. 서버는 **싱가포르(AWS)** 에 있습니다. 앱을 만든 사람이나 다른 학교는 이 데이터를 볼 수 없습니다.
- 이메일·전화번호 등 다른 학생 정보는 받지 않습니다.

**AI로 무엇이 가나**
- 피드백을 만들 때 **만다라트 글(목표·실천 행동)만** OpenRouter(미국)를 거쳐 AI 모델 제공사(국외)로 보냅니다.
- **학생 이름, 번호, PIN은 AI로 보내지 않습니다.**
- 앱은 요청할 때마다 "입력 내용을 학습에 쓰지 않고 보관하지 않는 제공사만 써 달라"고 OpenRouter에 지정합니다.
- 교사 화면의 **AI 연결 확인** 은 정해 둔 짧은 확인 문장만 보내고, 학생 글은 보내지 않습니다.
- 다만 학생이 만다라트 칸에 직접 이름이나 연락처를 쓰면 그 글은 AI로 갑니다. **만다라트에 실명·연락처·다른 사람 이야기를 쓰지 않도록** 수업 전에 안내해 주세요.

**⚠️ 안전 신호**
- 교사 화면에만 보이고, 학생 화면과 CSV 파일에는 들어가지 않습니다. 진단이 아니라 직접 살펴보라는 힌트입니다([수업 사용 안내 2-4](수업_사용_안내.md#2-4-안전-신호가-보이면)).
- 학급 화면의 학생 이름과 종류, 학생 상세 화면의 종류·걸린 칸·AI 신호 표시는 기본으로 숨겨져 있고, **안전 신호 보기** 를 누를 때만 보입니다(화면을 TV·프로젝터에 띄운 채 누르지 마세요).

**학교에서 확인할 것**
- 학생 글이 국외 AI 서비스로 전송되므로, 학교에 따라 **가정통신문 안내나 보호자 동의**가 필요할 수 있습니다.
- 명렬표(이름)가 국외(싱가포르) 클라우드에 저장된다는 점도 함께 안내하는 것이 좋습니다.

**다 쓴 뒤 지우기**
- 학급 하나만 지우려면 학급 화면 맨 아래 **학급 지우기** 를 씁니다(되돌릴 수 없음).
- 앱 전체를 정리하려면 학급 결과를 CSV로 내려받아 둔 뒤, Vercel 대시보드 > 프로젝트 > **Storage** 에서 Neon 데이터베이스를 삭제합니다. 저장된 모든 자료가 지워집니다.
- OpenRouter 키는 OpenRouter **Keys** 메뉴에서 삭제할 수 있습니다.

## 9. 문제 해결

화면에 나온 문구로 찾으세요.

### 설치·설정 화면

| 증상(화면 문구) | 원인과 해결 |
|---|---|
| Deploy 중 GitHub·Vercel 로그인이 안 됨 | 학교 계정이 외부 로그인을 막는 경우가 많습니다. 개인 이메일로 만든 GitHub 계정으로 다시 하세요. |
| 배포(Deploy)가 빨간색 **Error** 로 끝남 | Vercel 대시보드 > 프로젝트 > **Deployments** 에서 실패한 항목을 누르고 **Redeploy** 를 한 번 눌러 보세요. 그래도 안 되면 실패 화면의 로그(Build Logs)를 연수 담당자에게 보여 주세요. (데이터베이스나 키가 없어도 빌드는 끝납니다. 그런 문제는 아래 `/teacher/setup` 화면에 나옵니다.) |
| 환경 변수를 고쳤는데 그대로임 | 값을 바꾼 뒤에는 **Deployments > 맨 위 항목 > Redeploy** 를 눌러야 적용됩니다. |
| `/teacher/setup` 에 ⚠️ "[설정 오류] 데이터베이스 주소(DATABASE_URL)가 없습니다…" | Neon이 프로젝트에 연결되지 않았습니다. Vercel > 프로젝트 > **Storage** 에서 Neon 데이터베이스를 만들거나 골라 **Connect** 합니다(접두사 prefix는 비워 둠). 그다음 **Deployments > Redeploy**. |
| `/teacher/setup` 에 ⚠️ "데이터베이스에 연결하지 못했습니다…" | 잠시 뒤 새로 고쳐 봅니다(오래 쉬던 무료 DB가 깨어나는 중일 수 있음). 계속되면 Vercel > **Storage** 에서 Neon 연결을 확인하고, Neon 콘솔의 **Usage** 에서 무료 한도를 넘지 않았는지 봅니다. |
| `/teacher/setup` 에 ⚠️ "설정 코드(SETUP_TOKEN)가 없거나 16자보다 짧습니다…" | Vercel > Settings > Environment Variables 에 `SETUP_TOKEN` 을 넣고(20자 이상 무작위 권장, [1-4](#1-4-설정-코드setup_token-만들기)) Redeploy 합니다([6-2](#6-2-설정-코드setup_token-바꾸기)). |
| "설정 코드가 맞지 않습니다." | 입력한 코드가 Vercel에 넣은 `SETUP_TOKEN` 과 다릅니다(앞뒤 빈칸은 상관없음, 대소문자는 구분). 메모해 둔 값을 다시 확인하세요. 잊었다면 [6-2](#6-2-설정-코드setup_token-바꾸기)로 새로 정합니다. |
| "이미 교사 계정이 있습니다…" | 정상입니다. `/teacher/login` 에서 로그인하세요. 비밀번호를 잊었다면 [6-1](#6-1-교사-비밀번호를-잊었을-때). |
| 교사 로그인에서 "아이디나 비밀번호가 맞지 않습니다." | 아이디·비밀번호를 확인합니다. 여러 번 틀리면 점점 느려지니 잠시 기다렸다가 하세요. 잊었다면 [6-1](#6-1-교사-비밀번호를-잊었을-때). |
| 비밀번호 다시 정하기에서 "그 아이디의 교사 계정이 없습니다. 이 앱의 교사 아이디: …" | 설정 코드는 맞았고 교사 아이디가 틀렸습니다. 화면에 나온 아이디로 다시 하세요. |
| 학생·교사 화면에 "잠시 문제가 생겼어요." 와 **다시 시도** 버튼 | 화면을 만들다 서버에 문제가 생겼습니다(대부분 데이터베이스에 잠깐 연결하지 못한 경우). **다시 시도** 를 누르거나 잠시 뒤 새로 고칩니다. 계속되면 `/teacher/setup` 을 열어 ⚠️ 문구를 이 표에서 찾습니다. |
| "찾는 화면이 없어요." | 주소가 틀렸거나, 지운 학급·학생의 화면입니다. **학생 첫 화면** 또는 **교사 화면** 버튼으로 이동하세요. |

### AI 피드백

| 증상(화면 문구) | 원인과 해결 |
|---|---|
| 교사 화면에 AI 키가 없다는 노란 안내, 학생 화면에 "선생님이 아직 AI 피드백을 준비하지 않았어요. 만다라트는 계속 쓸 수 있어요." | `OPENROUTER_API_KEY` 가 없습니다. Vercel 환경 변수에 넣고 Redeploy 합니다. |
| 학생 화면에 "피드백을 만드는 중 문제가 생겼어요. 잠시 후 다시 눌러 주세요." | AI 요청이 실패했습니다. 교사 화면 위쪽의 빨간 상자("⚠️ 최근 24시간 동안 AI 피드백을 만들지 못한 적이 N번 있습니다.")를 보거나 **AI 연결 확인** 을 눌러 원인을 봅니다(아래 [AI 오류 문구 읽는 법](#ai-오류-문구-읽는-법)). 한 명만 한 번 그랬다면 잠시 뒤 다시 누르게 하면 됩니다. |
| 학생 화면에 "피드백을 만드는 데 너무 오래 걸리고 있어요…" | AI가 붐벼 늦어지고 있습니다. 1~2분 뒤 다시 누르게 합니다. |
| 학생 화면에 "피드백을 반영할 시간을 가진 뒤 다시 요청해 주세요. N초 뒤에 받을 수 있어요." | 정상입니다. 피드백을 받은 뒤 30초 동안은 다음 피드백을 받을 수 없습니다(카드를 읽고 고칠 시간, AI 비용 절약). |
| 학생 화면에 "이미 피드백을 만들고 있어요. 잠시 뒤 화면에 나타나요." | 같은 학생이 버튼을 여러 번 눌렀거나 다른 기기·다른 단계에서 동시에 요청했습니다. 지금 만드는 피드백이 끝날 때까지 기다리면 됩니다(겹친 요청은 AI를 부르지 않아 비용이 들지 않습니다). |
| 학생 화면에 "피드백을 만드는 데 여러 번 실패했어요. 선생님께 말씀드려 주세요. (몇 분 뒤에 다시 해 볼 수 있어요)" | 그 학생의 피드백 요청이 최근 5분 안에 3번 실패해서, 앱이 잠시 요청을 막았습니다(실패가 이어지며 AI 비용이 새지 않게). 교사 화면 위쪽의 빨간 상자나 **AI 연결 확인** 으로 원인을 고치면, 몇 분 뒤 다시 받을 수 있습니다. |

#### AI 오류 문구 읽는 법
교사 화면 위쪽에는 두 곳에 실패 이유가 쉬운 말로 나옵니다(학생 이름이나 글은 나오지 않습니다).
- **AI 연결 확인** 을 누른 결과: "✅ AI 연결 정상" 또는 "⚠️ AI 연결에 문제가 있습니다" 와 그 이유. 문제가 있으면 옆 괄호에 OpenRouter의 응답 번호(예: '(응답 402)')가 붙고, AI가 제때 답하지 않았으면 '(시간 초과)', 연결하지 못했으면 '(연결하지 못함)' 이 붙습니다.
- 학생 피드백이 실패한 적이 있을 때만 나오는 빨간 상자: "⚠️ 최근 24시간 동안 AI 피드백을 만들지 못한 적이 N번 있습니다." 최근 10건까지 세고, 같은 이유는 한 줄로 묶어 마지막 시각과 횟수를 보여 줍니다. 실패가 없으면 이 상자는 나오지 않습니다.

대표적인 문구와 할 일입니다.

| 교사 화면 문구(앞부분) | 뜻 | 할 일 |
|---|---|---|
| "AI 키(OPENROUTER_API_KEY)가 없습니다…" | 키를 넣지 않았습니다. | Vercel 환경 변수에 넣고 Redeploy. |
| "AI 키가 맞지 않거나 지워졌습니다(401)…" | 키가 틀렸거나 OpenRouter에서 지워졌습니다. | OpenRouter **Keys** 에서 키를 새로 만들고 Vercel의 `OPENROUTER_API_KEY` 를 바꾼 뒤 Redeploy([6-4](#6-4-openrouter-키-바꾸기)). |
| "OpenRouter 크레딧이 부족하거나 키 사용 한도에 닿았습니다(402)…" | 충전 잔액이 없거나 키의 Credit limit에 닿았습니다. | OpenRouter **Credits** 에서 충전하거나 **Keys** 에서 한도를 올립니다. **바로 다시 됩니다(Redeploy 불필요).** |
| "설정된 AI 모델 이름을 OpenRouter에서 찾지 못했습니다…" | `OPENROUTER_MODEL` 의 모델 ID가 틀렸거나 그 모델이 없어졌습니다. | `OPENROUTER_MODEL` 을 비워 기본 모델로 두거나 https://openrouter.ai/models 에서 ID를 정확히 복사해 넣고 Redeploy. |
| "AI 요청이 한꺼번에 너무 많았습니다(429)…" | 짧은 시간에 요청이 몰렸습니다. | 잠시 뒤 다시 하면 됩니다. 수업 중 자주 나오면 학생들이 한꺼번에 누르지 않게 나눠 줍니다. |
| "학생 글을 보관하지 않는 조건(ZDR)에 맞는 AI 제공사를 지금 찾지 못했습니다(404)…" | 앱은 학생 글을 학습에 쓰지 않고 보관하지 않는 제공사만 쓰도록 요청하는데, 지금 맞는 제공사가 없습니다. | 잠시 뒤 다시 해 봅니다. 계속되면 OpenRouter **Settings > Privacy** 를 기본값으로 두고, `OPENROUTER_MODEL`·`OPENROUTER_PROVIDERS` 를 바꿨다면 비워서 기본 모델로 돌아갑니다(Redeploy). |
| (AI 연결 확인) "이 모델(…)은 있지만, 학생 글을 보관하지 않는 조건(ZDR)을 지키는 AI 제공사가 없습니다(404)…" 또는 "…(ZDR)과 이 앱이 쓰는 JSON 응답 형식을 함께 지키는 AI 제공사가 없습니다(404)…" | 모델 이름은 맞지만, 그 모델에는 학생 글 보호 조건(과 이 앱이 쓰는 응답 형식)을 지키는 제공사가 없습니다. 기다려도 대개 그대로입니다. | `OPENROUTER_MODEL` 에 다른 모델을 넣거나 비워서 기본 모델로 돌아가고, `OPENROUTER_PROVIDERS` 를 넣었다면 비운 뒤 Redeploy([6-5](#6-5-ai-모델-바꾸기-openrouter_model-보통-건드리지-않음)). 학생 글 보호 조건은 끌 수 없으니 OpenRouter의 개인정보 설정은 그대로 두세요. |
| "…내용 검사에서 요청이 거절되었습니다(403)…" / "AI 모델이 응답을 거절했습니다…" | 학생 글 때문에 AI 쪽에서 거절했을 수 있습니다. | 그 학생의 글을 직접 읽어 보세요(⚠️ 안전 신호와 같은 마음으로). |
| "…잠깐 문제가 있었습니다(5xx)", "…시간 초과로 끝났습니다", "OpenRouter에 연결하지 못했습니다", "…형식이 맞지 않았습니다", "…길이 제한에서 잘렸습니다" | 일시적인 문제입니다. | 잠시 뒤 다시 하면 대부분 됩니다. |

### 학생 로그인·PIN

| 증상(화면 문구) | 원인과 해결 |
|---|---|
| "학급 코드, 번호, 이름, PIN을 확인해 주세요." | 넷 중 하나가 틀렸습니다. 이름은 명렬표와 똑같이 써야 합니다. 틀릴 때마다 잠금 횟수에 들어갑니다. |
| "여러 번 틀려서 잠시 잠겼어요. N분 뒤에…" / "여러 번 틀려서 잠겼어요. 선생님께 풀어 달라고 말씀드리세요." | PIN을 8번 틀리면 잠깁니다(24시간 안에 처음은 10분, 두 번째는 60분, 세 번째부터는 선생님이 풀 때까지). 학급 화면 > 그 학생 줄의 **잠금 해제** 를 누르면 바로 풀립니다. 잠금 단계도 처음으로 돌아가, 다시 8번 틀리면 10분 잠금부터 시작합니다. 정확한 PIN을 확인해 주고(학생 PIN 보기) 풀어 주세요. |
| 여러 학생이 한꺼번에 잠김 | 학급 코드를 아는 누군가가 다른 학생의 번호로 일부러 PIN을 틀리면 그 학생이 잠깁니다. 학생 표 위의 **잠긴 학생 모두 풀기 (N명)** 로 한 번에 풀고, 학생들에게 학급 코드를 수업 밖에 올리지 말고 남의 번호로 로그인하지 말라고 이야기해 주세요([수업 사용 안내](수업_사용_안내.md#자주-생기는-상황)). |
| 학생이 PIN을 잊음 / 카드를 잃어버림 / 친구가 PIN을 앎 | 학급 화면 > 학생 표 위의 **학생 PIN 보기** 를 켠 뒤, 그 학생 PIN 칸의 **다시 만들기** 를 누릅니다. 이전 PIN은 더 이상 쓸 수 없고, 그 PIN으로 로그인해 있던 기기도 로그아웃됩니다. 잠금도 풀리고, 다음 잠금은 다시 10분부터입니다. 학생이 쓴 글은 그대로 남습니다. |

### 그 밖

| 증상 | 원인과 해결 |
|---|---|
| 몇 주 만에 열었더니 첫 화면이 몇 초 느림 | 정상입니다. 무료 Neon 데이터베이스는 쓰지 않을 때 잠들었다가 첫 접속 때 깨어납니다(보통 1~2초 이내). 두 번째부터는 빠릅니다. 수업 직전에 교사가 한 번 열어 두면 좋습니다. |
| Neon 무료 한도 초과 | 프로젝트마다 월 100 CU-시간, 저장 0.5~1 GB(공식 문서 안에서도 표기가 다름, 2026-10 확인)가 무료 한도입니다. 계산 시간을 넘으면 다음 사용 기간(매달 계정 기준일)까지 데이터베이스가 멈추고, 저장 용량을 넘으면 새로 저장할 수 없습니다. 데이터는 지워지지 않습니다. 학급 몇 개를 가끔 쓰는 정도로는 **넘지 않습니다.** Neon 콘솔의 **Usage** 페이지에서 정확한 한도와 사용량을 확인하세요. |
| **앱 업데이트** 가 빨간 ✗ 로 끝남 | 실패한 실행을 눌러 빨간 단계의 로그를 연수 담당자에게 보여 주세요. "Permission denied" / "403" 이면 저장소 **Settings > Actions > General > Workflow permissions** 에서 **Read and write permissions** 를 고르고 Save 한 뒤 다시 실행합니다. |
| **Actions** 탭에 **앱 업데이트** 가 없음 | 왼쪽 목록에 안 보이면 Actions를 먼저 켜야 합니다([5. 앱 업데이트 받기](#5-앱-업데이트-받기)의 3번). 그래도 없으면 저장소에 `.github/workflows/update-from-template.yml` 파일이 있는지 확인하세요(오래전에 설치한 앱에는 없을 수 있음 → 연수 담당자에게 문의). |
| 앱 업데이트는 ✓ 인데 Vercel에 새 배포가 없거나 "blocked" | Vercel > 프로젝트 > **Deployments** 를 확인합니다. 새 배포가 없으면 Vercel > **Settings > Git** 에서 저장소가 연결되어 있는지 봅니다. "blocked"(작성자 확인) 문구가 있으면, 앱 업데이트를 실행한 GitHub 계정이 Vercel에 로그인한 계정과 같은지 확인하세요. |
